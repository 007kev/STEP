# First 3D Prints 🖨️

OpenSCAD is an open source 3d modeling software based on C++ that I am starting off with to enhance my projects


### Speaker Enclosure 

I started with a better enclosure for a bluetooth speaker kit from Amazon.

![Speaker Front](./images/speaker_OG.png)

On OpenSCAD I was mathemtically able to design a sturdier compartment for some of the components from the original kit. I used the original bluetooth module and amplifier.

![Speaker Shell](./images/speaker_openSCAD.png)

Programming basic algebra and geometry on the C++ based software. I only highlighted in red some of the shapes that were removing material, it was programmed using a difference() function.

I also used a chicago brand vernier caliper to get within 0.02mm of measurement, which results in a 5% relative uncertainty. My Bambu labs A1 Mini has a stock nozzle diameter of 0.4mm. 

![Speaker Shell](./images/speaker_front.png)

For portability, I also 3D printed a three AA battery compartment and wired it in series to a 5V dc - dc converter and in series again to a switch in the back.
